# 人体动作参考与对照验收

建立日期：2026-10-30。适用于新动作和已有动作修订；器械仍遵循独立的器械参考规范。

## 来源与记录

每项动作独立记录项目 ID、动作名称、器械、握法、站/坐/卧姿、单/双侧及支撑点。同一动作家族可以共享来源，但必须解释每个变体的匹配关系；双臂示范不能直接充当单臂躯干稳定性的证据。

至少取得一份匹配变体的真人完整示范，并用可信机构的动作说明核对关键要点。以视频优先；仅有图片时需覆盖起点、中间与终点，并补足回程及路径信息。主镜头遮挡关键关节时增加侧面来源或自摄参考。来源不足时标记 `needs_reference`，不靠动作名称猜轨迹。

记录以下内容：

- 第一方发布者、页面 URL、访问日期、图片位置/视频时间码及真实观察内容；搜索摘要和缩略图不算已看过示范。
- 真人教学、真人动捕、姿态估计或合成动画的类型，拍摄视角、示范者角色，以及变体差异。
- 媒体、数据和代码各自的许可；网页可看、可下载、可转存、可再分发、可供 AI 工具生成派生内容是不同权限。未确认的权限明确记为未知，不将付费 API 或开源代码许可套到媒体。
- 未获本地保存许可时仅记录链接和时间码；不把受限媒体放进仓库或 App。网页访问也须遵守来源条件。
- 采用哪些动作要点、哪些存在冲突、如何取舍；授权或覆盖不足的来源只列候选，不进入生成素材链。

## 制作与验收

1. 在实现轨迹前填写动作规格：运动平面、肘膝屈伸方向、上臂与前臂轴转、肩带配合、握法、负重路径及支撑关系。数值必须说明坐标系、依据和适用动作，不能把某一动作示范角度当作所有人的生理极限。
2. 真人关键姿态与男女渲染逐阶段、尽可能同视角对照；不得用换镜头掩盖不合理关节。单臂主镜头继续位于负重侧。
3. 全循环检查动作专用约束、关节旋转连续性、接触、碰撞、形变、闭环；姿态估计或骨长正确不能替代人体动作审核。
4. 将已发生的错误姿态作为回归反例。若检测仍允许旧错误姿态，不能因新场景通过而称缺陷已防住。
5. 实际查看关键帧和完整动作后，分别记录男女审核意见、参考位置、场景和渲染证据摘要。缺少专业人员复核时，不称为“专业动作验收”。

## 当前程序入口

`db_upright_row.json` 与 `single_upright_row.json` 记录本次实际查看的真人示范链接、时间码、动作观察与采用范围；保存的是自写观察，不下载、抽取姿态或再分发真人视频。单臂来源为 Functional Bodybuilding 的 [Single Arm Dumbbell Upright Row](https://www.youtube.com/watch?v=kSrITY6J7qo)，双臂为 PureGym 官方视频。

`motion_reference_gate.py` 在烘焙前核对记录，在全帧审核时生成独立报告，并在正式渲染、打包、同步时核对场景/规格/参考/检查器摘要与四阶段目视审核。`compose` 产生 pending 模板，禁止自动接受。当前直立划船专用幅度上限为选定示范的90°，同时约束屈肘、前臂方向、腕线和峰值负重位置；不推广为通用人体活动极限。

`legacy-scenes.json` 的84条记录只兼容其余42个库动作的原场景与原规格，状态为历史待补参考；不允许这些动作在无参考时重新烘焙。其他19个计划动作尚未迁移到本门禁。全库精确参考覆盖仍需分批补齐。
