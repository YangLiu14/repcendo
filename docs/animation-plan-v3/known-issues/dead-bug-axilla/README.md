2026-10-29 更新：男女两版已加入肩腋姿态修正，重新生成视频、封面并同步 App。当前场景通过完整 193 帧拉伸/形变/穿模检查、网格闭环和正侧背/肩腋近景审核。原有大面积侧肋拉伸明显收回；局部雕塑折痕与衣褶仍存在。

这次保留原 Armature / DQ 蒙皮，用局部保形求解和躯干/上臂体积引导生成 Shape Keys，再处理插值帧的接触。女性前肩衣褶采用随抬臂相位渐变的保护。没有修改骨架轨迹、原始网格坐标、UV 或肌群材质。它是当前死虫式的校准配方，不是全动作肩部绑定已经解决的证明。

当前逐帧肩腋 p95 最大值：男性 **1.79515**，女性 **1.79699**；原工程阈值 **1.8** 和碰撞 **2 mm** 容差未变。两版闭环误差均为 0，全部骨姿态矩阵与旧场景一致。当前证据见 `../../male/dead_bug-strain.json`、`../../female/dead_bug-strain.json`、对应 `dead_bug-preservation.json` 和 `../../deformation-review/`。制作流程见 `../../../animation-pipeline.md`。

```sh

  --python Scripts/animation_samples/diagnose_torso_strain.py -- \
  --scene build/axilla-rebuild/before-delivery/docs/animation-plan-v3/male/dead_bug.blend \
  --output build/axilla-repair/repro-male.json
```

将 male 换为 female 可检查女性。检查真实蒙皮和全部修饰器求值后的网格，覆盖 1、49、97、145、193 帧。肋侧/腋窝校准区域的边长比第 95 百分位在男性第 145 帧为 2.791、女性第 49 帧为 2.925。报告中的 1.8 是本缺陷的工程回归阈值，不是人体生理界限，也不能单独作为验收条件；错误地把整个上臂绑回躯干也可能降低这一数值。

## 已确认与尚未确认

- 原权重存在局部肋侧顶点受上臂、大腿影响的现象；交界处也有上臂/躯干混合影响。它们是可疑机制，但尚未证明它们能单独解释完整形变。
- 关闭垫面接触修正后，男性第 145 帧边长比 p95 从 2.791 变为 2.793，形状基本不变，因此垫面不是主因。
- 单独增加锁骨抬升、切换线性蒙皮、分区重分配权重、Blender 热权重重绑，都没有得到合格画面。
- 基于边长的姿态修正能缩小外扩，但会导致腋下凹陷/折叠；局部 Corrective Smooth 也未解决。未把这些候选放入生产。
- 表面连通/距离权重原型会损害上臂体积；它们是失败实验，不是可复用生产算法。
- 轴向旋转探针的求值指标未改善；它的渲染会受动作重求值影响，因此那组 PNG 不能作为“修改轴转无视觉效果”的证据。

需要重新审视肩腋局部绑定及原始表面结构，制作能保留上臂体积与肋廓轮廓的姿态修正；若现有拓扑无法支持，再做局部重拓扑。尚未确认必须更换整个角色，不能仅凭本次失败试验下该结论。先完成一个男性死虫式的抬臂全程，再复用到女性。

必须在保持动作轨迹、骨长和主要肌群纹理的前提下，同时查看躯干侧面/背面/上臂近景，核对收回与左右交替；再运行完整循环形变、碰撞与闭合检查。不能靠缩小动作幅度、换镜头或只降低边长指标宣称完成。
