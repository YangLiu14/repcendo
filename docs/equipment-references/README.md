# 器械照片参考与验收

制作或修改器械前，先完成这些步骤：

1. 在网上找到至少一张能看清结构的真实产品照片，优先厂家产品页。实际打开并查看图片；只有搜索结果标题、文字描述或 AI 生成图不算完成。关键结构被遮挡时补找其他角度或官方说明书。
2. 在本目录为器械保存参考记录：型号、产品页 URL、照片 URL、查看日期、观察到的结构、适用动作，以及为了本项目做的简化。`pec-deck.json` 是第一份记录。照片仅作建模参考；App 使用本项目生成的资产。
3. 建模前确定固定支架、座椅/靠垫、转轴位置、移动杆件、握把和阻力来源。刚性杆件保持长度，滑轨保持轴线；先建立器械运动约束，再让手脚匹配器械。外观可简化，支撑和运动原理应保留。
4. 输出准备、行程中点、最大行程的主镜头与侧视图，逐项对照照片。检查人体朝向、握持、靠垫支撑、杆件连接和完整运动轨迹，再进入原有形变、碰撞、循环与媒体验收。
5. 审核说明同时记录结构对应关系和简化限制。碰撞通过只说明接触检查通过，不能替代器械结构审核。现有旧模型不因新增流程自动获得照片验收。

蝴蝶机示例采用 Life Fitness SS-FLY 的结构参考：顶部双竖直转轴、横向摆臂及下垂握臂、共用胸背靠垫、可调座椅、配重塔和连接底座。项目配色及人物适配尺寸由我们制作，不作为该型号的工程复刻。夹胸背向靠垫，反向飞鸟面向靠垫；两种模式的杆件都应绕转轴运动，而非伸缩追随拳头。

2026-10-30 全库现有资产复核参考来自 [Life Fitness / Hammer Strength 2025 官方目录](https://www.lifefitness.com.au/wp-content/uploads/2025/04/LF-HS_ProductCatalogue_2025_low-res.pdf)：PDF 第 34 页腿屈伸/坐姿腿弯举，第 37 页斜轨腿举，第 39 页训练凳，第 44–45 页哑铃/杠铃/训练垫，第 48 页高低位绳索站，第 75 页站姿提踵。实际查看了这些页面照片；`equipment-audit.json` 记录建模来源。第 45 页薄矩形训练垫与现有地面动作的简化垫结构一致，无需改动。

本轮采用原创简化结构而非厂家 CAD：腿机双侧独立膝轴适配人物校准差异；提踵以竖直滑车加小行程水平导向承托肩垫，保留肩部承力和配重路径，未复刻 HS-SC 连杆。图示不是器械装配或制造图。

新增 `equipment_refit.py` 在人体接触面拟合后补全硬件。`verify_equipment_refit.py` 对完整循环检查固定件不漂移、连杆不伸缩、脚踏板沿轴线滑动、配重位移对应拉出绳长；可通过 `--before` 对照修改前场景的每帧人体网格摘要，证明人物未改变。主/侧三姿势证据仍需人工与照片对照，不能由自动检查代替。发布由 `equipment_gate.py` 绑定场景、检查器、照片记录和审核图片摘要。
