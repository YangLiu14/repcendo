# 人物肢体自然度修复

2026-10-30。范围为现行制作流程中的 55 个动作、110 个男女版本；旧版深蹲（0043）的两段历史媒体保留，仍待按现行流程复核。本次不增加动作库覆盖数。

## 缺陷与修正

- 小腿肌腹过圆、膝盖前侧过凸：在制作副本的静止空间局部收敛轮廓，男女使用不同强度，平滑过渡到跟腱与膝部。保持足底、腿长、拓扑、UV 和权重，原始雕塑不覆盖。
- 安静站姿屈膝过多：旧实现固定下降髋部 32 mm，代表弯举实际约屈膝 33°。新实现按实际骨长和站距求解 6° 目标；RDL、深蹲保留自己的髋膝轨迹。
- 抬臂时侧胸和肩腋鼓起：在混合肩带权重区域添加局部姿态修形，手臂、肘、腕、手指不加入该修形。平卧推举和死虫式保留各自肩部解法；男性四个中立握/交替推举采用较低混合强度。

同角度、同姿势对照：[男性](male-comparison.jpg) · [女性](female-comparison.jpg)。对照不能替代每个动作的完整验收。

## 验收方法

每个候选重新烘焙，逐帧检查双向人体/器械碰撞、自穿插、关节形变、动作轨迹与循环；保留 2 mm 穿模容差。逐项实际查看人体多视角、手部近景和适用的器械接触证据后才写入接受记录。肩带全强度导致腋下穿插的平卧与中立握试验已拒绝，未通过放宽容差接受。

动作库采用各自 v1/v3/v4/v5 专用检查；训练计划额外检查真实手掌表面、支撑、卷腹握持方向、死虫肩腋拉伸及器械机构。所有接受记录绑定实际场景和图片 SHA-256；正式媒体再绑定渲染源和输出摘要。
